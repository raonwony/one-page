# One.Page (웹앱)

생각을 받은함에 던져두고, 노트에 붙여 정리하는 개인 메모 앱의 웹(PWA) 버전입니다.
기존 Flutter 앱(`note_app`)과 같은 구글 드라이브 백업 파일(`note_app_backup.json`)을 읽고 쓰므로, 기존 메모가 그대로 이어집니다.

- 맥 앱 서명(1주일 만료) 문제가 없습니다 — 브라우저/설치형 웹앱이라 애플 개발자 서명이 필요 없습니다.
- 메모는 먼저 이 기기(IndexedDB)에 저장되고, 구글 로그인이 풀려도 내용은 사라지지 않습니다.
- 안드로이드: 크롬에서 "홈 화면에 추가" → 공유 메뉴에 One.Page가 나타나 링크·글을 바로 받은함으로 보낼 수 있고, 앱 아이콘을 길게 누르면 "빠른 메모" 바로가기가 있습니다.
- 맥: 크롬/사파리에서 "독에 추가"(Safari) 또는 "설치"(Chrome)로 앱처럼 사용.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 생성 (서비스워커·매니페스트 포함)
```

## 배포 (GitHub Pages)

1. 이 폴더를 새 GitHub 저장소(예: `one-page`)에 올립니다.
2. `github-pages-deploy.yml` 파일을 `.github/workflows/deploy.yml`로 옮깁니다. (블러 에디터 저장소의 같은 파일을 복사해도 됩니다)
3. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. (push하면 자동 배포)
4. 배포된 주소는 `https://<아이디>.github.io/<저장소>/` 입니다.

## 구글 로그인 설정 (한 번만)

[Google Cloud Console](https://console.cloud.google.com/) → 기존 Flutter 앱을 만들 때 쓴 프로젝트 → API 및 서비스 → 사용자 인증 정보.

1. 클라이언트 ID `352345649881-575nkkmg…`(웹 애플리케이션) 편집 → **승인된 JavaScript 원본**에 `https://<아이디>.github.io` 추가 (경로 없이 도메인만). 로컬 테스트용으로 `http://localhost:5173`도 추가할 수 있습니다.
2. OAuth 동의 화면 → 게시 상태가 **테스트 중**이면 **프로덕션으로 게시**하세요. 테스트 중이면 구글이 7일마다 로그인을 풀어 버립니다. 이 앱이 쓰는 권한(`drive.appdata`, 이메일)은 민감 범위가 아니라서 구글 검수 없이 게시됩니다.

다른 클라이언트 ID를 쓰고 싶으면 빌드 시 `VITE_GOOGLE_CLIENT_ID` 환경변수로 덮어쓰면 됩니다. (`src/config.ts`)

## 동기화 방식

- 변경 후 몇 초 뒤, 앱을 다시 열 때, 화면을 떠날 때 자동으로 동기화합니다. 설정 화면의 "지금 동기화"로 직접 할 수도 있습니다.
- 로그인이 풀리면 설정 화면에 "다시 연결" 버튼이 나타납니다. 내용은 이 기기에 그대로 있습니다.
- 병합 규칙은 기존 앱과 같습니다: 수정 시각이 더 최근인 쪽이 이기고, 노트에서 뺀 메모지는 삭제가 우선합니다.

## 알려진 제한

- 링크 미리보기(제목·썸네일)는 브라우저 보안(CORS) 때문에 가져오지 못해 도메인만 표시합니다. 기존 앱에서 이미 가져온 미리보기는 그대로 보입니다.
- 노트 안 메모지 순서는 기기 간에 합쳐지지 않습니다 (기존 앱과 동일한 제한).
- 안드로이드 공유로 이미지를 받는 기능은 없습니다 (텍스트·링크만). 이미지는 앱 안에서 사진 고르기 또는 붙여넣기로 추가하세요.
